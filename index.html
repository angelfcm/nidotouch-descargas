Antes de conectar la tablet

Necesitas Android 11 o posterior, un cable USB de datos y acceso al usuario principal. La computadora necesita Java 17 o posterior y Android Platform-Tools.

Puedes revisar la compatibilidad con tus datos actuales. Si decides quitar una cuenta, comprueba antes que lo importante esté sincronizado. El asistente te deja salir sin cambios durante la revisión.

Probado en macOS con Android 16 emulado. La prueba en Windows con una tablet conectada por USB sigue pendiente.
